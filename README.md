## `> LINUX ENVIRONMENT // ARCH LINUX`

<div align="center">

<img src="https://skillicons.dev/icons?i=arch,linux&theme=dark" alt="Arch Linux" />

</div>

O Arch Linux é meu ambiente de desenvolvimento. Gosto da filosofia dele: simples, minimalista e com o usuário no controle. É um sistema **rolling release**, com atualizações contínuas, que usa o **pacman** como gerenciador de pacotes e conta com o **AUR** (Arch User Repository) como parte do ecossistema.

```text
[SYSTEM STATUS]
─────────────────────────────────────
OS               : ARCH LINUX
ENVIRONMENT      : LINUX
RELEASE MODEL    : ROLLING RELEASE
SHELL            : [EDITAR: bash / zsh / fish]
DESKTOP / WM     : [EDITAR: ex. KDE, GNOME, i3, Hyprland]
EDITOR           : VS CODE
PACKAGE MANAGER  : PACMAN (+ AUR)
DEVELOPMENT      : ACTIVE
─────────────────────────────────────
```
